# GROWalition.org

Static site for GROWalition, the coalition planting one billion native trees in a single day.

- Edit `src/page.html`, then run `./build.sh` to regenerate `index.html`.
- `index.html` is fully self-contained (only Google Fonts load externally), so it can be dropped on any static host (Netlify, GitHub Pages, etc.) with this folder as the publish directory.
