Connect your X account

Canopy reads your DM inbox through the X API and only replies to people who already messaged you. Reads and sends are billed to your own X developer app.

Paste a user access token instead

Use this if you minted a token yourself. It needs dm.read, dm.write, tweet.read and users.read. An app-only Bearer Token won't work for DMs.
